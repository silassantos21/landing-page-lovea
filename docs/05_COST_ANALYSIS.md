## Análise de ROI

O custo operacional mensal é praticamente zero (apenas domínio, ~R$10/mês). Uma única venda gerada pela landing page já cobre meses de operação. Considerando que o público-alvo (mulheres 25-45 anos, classes A/B) realiza compras médias de R$150-400 em moda, basta 1 venda/mês via WhatsApp originada pela página para ROI positivo imediato. O principal indicador de sucesso é o número de cliques no botão WhatsApp (rastreável via GA4 Events) e o crescimento orgânico nos resultados de busca local. Com SEO local bem executado, espera-se retorno orgânico consistente a partir do 2º ou 3º mês pós-publicação.

## Notas sobre Escalabilidade de Custos

- Preços baseados em uso inicial (MVP/early stage)
- Custos aumentam com volume de usuários e dados
- Reavalie a stack se atingir 10k+ usuários ativos
- Considere contratos anuais para economias de 20-40%
